# 05. Functions and Callbacks

**Prerequisite:** Complete the previous lesson.

## Objectives

Type parameters, return values, defaults, rest parameters, and callbacks.

## Explanation

A function type is a contract for input and output. Explicit return types are most valuable on exported functions.

> **বাংলা নোট:** Public function-এর return type refactor-কে নিরাপদ করে।
