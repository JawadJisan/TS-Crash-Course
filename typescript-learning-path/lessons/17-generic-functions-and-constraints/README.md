# 17. Generic Functions and Constraints

**Prerequisite:** Complete the previous lesson.

## Objectives

Write reusable functions that preserve input/output relationships.

## Explanation

Generics are type parameters. Constraints limit safe operations while preserving the caller's specific type.

> **বাংলা নোট:** Generic type input-output-এর সম্পর্ক বজায় রাখে।
