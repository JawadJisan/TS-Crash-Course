# 03. Arrays, Readonly Arrays, and Tuples

**Prerequisite:** Complete the previous lesson.

## Objectives

Model collections and fixed-position records without accidental mutation.

## Explanation

Arrays hold a variable number of one item type. Tuples give fixed positions distinct meanings. Readonly inputs communicate that a function only reads.

> **বাংলা নোট:** Array-এর length পরিবর্তনশীল; tuple-এর position নির্দিষ্ট অর্থ বহন করে।
