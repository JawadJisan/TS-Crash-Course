# 08. Narrowing and Type Guards

**Prerequisite:** Complete the previous lesson.

## Objectives

Refine union types using built-in checks and reusable predicates.

## Explanation

TypeScript narrows after typeof, instanceof, equality, truthiness, and in checks. A type predicate packages reusable validation.

> **বাংলা নোট:** Narrowing-এর পরে TypeScript নির্দিষ্ট type-এর property ব্যবহার করতে দেয়।
