# 01. Tooling and Your First Program

**Prerequisite:** Node.js 20+ and npm installed.

## Objectives

Understand the TypeScript compile/run cycle and write a typed function.

## Explanation

TypeScript checks JavaScript before it runs. Type annotations are removed from emitted JavaScript.

> **বাংলা নোট:** TypeScript runtime নয়; এটি code চলার আগে ভুল ধরতে সাহায্য করে।

## Run the Example

```powershell
npm.cmd run lesson -- typescript-learning-path/lessons/01-tooling-and-first-program/example.ts
```
