# 07. Literal Types and Unions

**Prerequisite:** Complete the previous lesson.

## Objectives

Constrain values to exact choices and combine related types.

## Explanation

A literal union expresses a closed set of allowed values and gives autocomplete plus invalid-state prevention.

> **বাংলা নোট:** Literal union দিয়ে অনুমোদিত value-এর তালিকা নির্দিষ্ট করা যায়।
