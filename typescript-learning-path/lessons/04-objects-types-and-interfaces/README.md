# 04. Objects, Type Aliases, and Interfaces

**Prerequisite:** Complete the previous lesson.

## Objectives

Describe reusable object shapes and readonly or optional properties.

## Explanation

Interfaces work well for extendable object contracts. Type aliases can also describe unions, primitives, and tuples. Consistency is more important than a rigid rule.

> **বাংলা নোট:** Object shape-এর জন্য type ও interface দুটোই ঠিক।
