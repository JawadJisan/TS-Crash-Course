# 27. Typed DOM and Events

**Prerequisite:** Complete the previous lesson.

## Objectives

Select DOM elements safely and type event handlers.

## Explanation

DOM selectors return nullable or generic elements. Narrow or throw when a required element is missing.

> **বাংলা নোট:** DOM selector nullable হতে পারে।
