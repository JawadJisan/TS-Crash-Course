# 22. Error Handling and Result Types

**Prerequisite:** Complete the previous lesson.

## Objectives

Choose between exceptions and explicit success/error results.

## Explanation

Exceptions suit exceptional boundaries; Result unions make expected failure visible to callers.

> **বাংলা নোট:** Expected failure Result-এ explicit রাখুন।
