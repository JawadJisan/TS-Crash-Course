# 24. Classes, Access Modifiers, and Interfaces

**Prerequisite:** Complete the previous lesson.

## Objectives

Use classes when identity, invariants, and behavior belong together.

## Explanation

Access modifiers and readonly properties control a class API. Interfaces describe capabilities independently.

> **বাংলা নোট:** Class-এর invariant method দিয়ে রক্ষা করুন।
