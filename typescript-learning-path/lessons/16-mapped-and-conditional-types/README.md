# 16. Mapped and Conditional Types

**Prerequisite:** Complete the previous lesson.

## Objectives

Create types that transform keys and branch based on a type.

## Explanation

Mapped types iterate over keys; conditional types choose a result based on assignability.

> **বাংলা নোট:** Mapped type key ধরে নতুন object type বানায়; conditional type condition অনুযায়ী type বেছে নেয়।
