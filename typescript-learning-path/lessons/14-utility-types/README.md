# 14. Utility Types

**Prerequisite:** Complete the previous lesson.

## Objectives

Transform existing object types with Partial, Required, Pick, Omit, and Record.

## Explanation

Utility types derive related contracts rather than duplicating them. This keeps models synchronized as the source type changes.

> **বাংলা নোট:** একটি source type থেকে utility type দিয়ে নতুন contract তৈরি করুন।
