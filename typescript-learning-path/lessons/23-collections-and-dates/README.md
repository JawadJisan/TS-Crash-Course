# 23. Map, Set, and Date

**Prerequisite:** Complete the previous lesson.

## Objectives

Use typed collections and keep date formatting at presentation boundaries.

## Explanation

Map supports typed keys and values; Set removes duplicates. Date represents an instant, not a display string.

> **বাংলা নোট:** Map key-value রাখে, Set duplicate সরায়।
