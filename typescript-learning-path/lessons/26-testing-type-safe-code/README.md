# 26. Testing Type-Safe Code

**Prerequisite:** Complete the previous lesson.

## Objectives

Write focused tests and separate pure logic from I/O.

## Explanation

Types prevent many mistakes, but tests verify behavior. Pure functions are easier to test than mixed I/O code.
