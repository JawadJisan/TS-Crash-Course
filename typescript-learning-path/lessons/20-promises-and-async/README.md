# 20. Promises and Async Functions

**Prerequisite:** Complete the previous lesson.

## Objectives

Type asynchronous values and compose sequential or concurrent work.

## Explanation

Async functions return Promises. Promise.all handles independent work concurrently.

> **বাংলা নোট:** async function-এর return type Promise হয়।
